# Whitelist Checker - Russia Mobile Internet

Приложение на PySide6 для проверки доступности IP-адресов, подсетей и доменов из репозитория [russia-mobile-internet-whitelist](https://github.com/hxehex/russia-mobile-internet-whitelist).

## Функционал

- Автоматическая загрузка данных из репозитория Russia Mobile Internet Whitelist
- Проверка доступности всех IP-адресов, подсетей и доменов
- Формирование минимальных подсетей из доступных IP-адресов
- Экспорт результатов в текстовый файл
- Графический интерфейс с отображением прогресса

## Установка

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Убедитесь, что у вас установлен git (для клонирования репозитория)

## Использование

1. Запустите приложение:

```bash
python whitelist_checker.py
```

2. Нажмите кнопку "Загрузить данные из репозитория" для получения списка адресов

3. Нажмите кнопку "Начать проверку" для запуска пинга всех адресов

4. После завершения проверки, во вкладке "Минимальные подсети" будут отображены:
   - Минимальные подсети, объединяющие все доступные IP-адреса
   - Список доступных доменов

5. Нажмите кнопку "Экспорт результатов" для сохранения результатов в файл

## Требования

- Python 3.7+
- PySide6
- netaddr
- ipaddress (входит в стандартную библиотеку Python)
- git (для клонирования репозитория)
